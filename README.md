# Kunjan Minama — AI Engineer Portfolio

A premium, recruiter-grade portfolio website built with pure HTML, CSS, and JavaScript. Designed to showcase production-grade AI engineering expertise.

## 🚀 Features

- **Dark theme** with glassmorphism design language
- **Animated particle background** (canvas-based, mouse-interactive)
- **Typing animation** cycling through AI titles
- **Live GitHub integration** (repos, stats, languages via API)
- **RAGAS metric counters** with animated numbers
- **AI architecture diagrams** (RAG, Agentic, Multi-Agent, MCP)
- **Scroll-reveal animations** via IntersectionObserver
- **Fully responsive** (desktop, tablet, mobile)
- **SEO optimized** with meta tags and semantic HTML

## 📁 Structure

```
├── index.html          # Single-page HTML
├── css/
│   └── styles.css      # Design system + all styles
├── js/
│   ├── main.js         # Navigation, scroll, typing, counters
│   ├── particles.js    # Canvas particle system
│   └── github.js       # GitHub API integration
└── README.md
```

## 🛠️ Tech Stack

- HTML5 (semantic)
- CSS3 (custom properties, glassmorphism, animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter, JetBrains Mono)
- GitHub REST API

## 📦 Deployment

Zero build step required. Deploy directly to:
- **Vercel**: Push to GitHub → Import → Deploy
- **Netlify**: Drag-and-drop the folder
- **GitHub Pages**: Enable in repo settings
